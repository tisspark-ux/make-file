## v0.02 (2026-04-15)

### 개선
- **전체 시트 색상 세련화**: 원색(네이비·진초록·빨강·보라·주황) → 뮤트 파스텔 팔레트로 통일
  - 헤더/레이블: `1F4E79→2E5F8A`, `375623→4A7A5A`, `C00000→B05050`, `7030A0→7A5CA8`, `FF8C00→C07A30`
  - 배경 셀: 연초록·연파랑·크림 등 부드러운 톤으로 조정
- **자산현황 대출잔액 자동 연계**: 월별 추이 H열(대출잔액)을 대출상환 스케줄에 수식으로 연결
  - 2026년 1~2월: 대출 실행 전 → 0
  - 2026년 3월: 대출 실행 월 → 원금 전액 (대출상환!C5 참조)
  - 2026년 4월~: 해당 회차 잔액 자동 참조 (`=IFERROR('대출상환'!$H$67, 0)` 등)
  - 연도 파라미터 지원 (`asset_sheet.build(wb, year)`)

## v0.01 (2026-04-14)

### 신규
- **대출상환 시트** 추가 (총 21번째 시트)
  - 기본 정보: 4.8억 / 4.07% / 30년 / 원리금균등
  - 금리 변동 이력 테이블: 총금리 직접 입력, MAXIFS 기준 자동 조회 (과거 소급 없음)
  - 월별 상환 스케줄 360행: PMT 매행 재계산 (금리변동·중도상환 자동 반영)
  - G열 중도상환 입력 → 이후 잔액·납입액 재계산
  - I열 'O' 입력 시 납입완료 표시 (녹색) + 요약 자동 반영
  - 요약 대시보드: 잔여원금·총이자·완료율·현재금리·완납예정일
- **대시보드 시트** 추가 (이번달 현황 한눈에 보기)
  - INDIRECT로 현재 월 시트 동적 참조
  - 수입/지출/잔액/예산/달성율/하루평균 요약 카드
  - 예산 vs 실제 지출 테이블 + 과소비 조건부 서식
- **결제수단 시트** 추가
  - UNIQUE/SUMPRODUCT로 카드·계좌별 월별 지출 자동 집계
  - 최대 30개 결제수단 동적 할당
- **분석 시트** 추가
  - 카테고리별 연간 예산 vs 실제 BarChart
  - 월별 × 카테고리 지출 히트맵 (ColorScale)
- **버전 관리** 도입
  - `version.py`: VERSION 상수 관리
  - 파일명에 버전 포함: `가계부_2026_v0.01.xlsx`
  - 설정 시트에 버전 표시

### 개선
- **자산현황 시트**: 월별 자산 추이 입력 테이블 + 순자산 꺾은선 차트 추가
- **요약 시트**: 미분류 거래 감지 섹션 추가 (FILTER+MATCH로 예산 카테고리 미매핑 지출 표시)

- 설정 시트 연도 1개 셀 변경으로 전체 갱신

- 수입/지출 월별 막대 차트 + 평균선 오버레이
